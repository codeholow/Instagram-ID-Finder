# 🔍 Instagram ID Finder

Extensão leve para navegador que identifica e exibe o ID numérico de qualquer perfil diretamente na interface do Instagram.

---

### 📌 Como Funciona

A extensão injeta uma *badge* com o ID numérico do perfil ao lado do nome de usuário. A extração é feita inspecionando os metadados e os scripts nativos carregados pela página.

---

### 📥 Como Importar a Extensão no Navegador

Como a extensão não está na Chrome Web Store, deves importá-la manualmente no teu navegador (Chrome, Edge, Brave, Opera, etc.):

1. Faz o download do código deste repositório (clica em **Code** > **Download ZIP**) e descompacta a pasta no teu computador.
2. Abre o navegador e acede à página de extensões:
   * **Chrome / Brave:** `chrome://extensions/`
   * **Edge:** `edge://extensions/`
3. No canto superior direito, ativa a opção **Modo do desenvolvedor**.
4. Clica no botão **Carregar sem compactação** (ou *Load unpacked*).
5. Seleciona a pasta descompactada onde estão os ficheiros do projeto (`manifest.json`, `content.js`, etc.).
6. Abre o Instagram e acede a qualquer perfil para ver o ID na tela.

---
